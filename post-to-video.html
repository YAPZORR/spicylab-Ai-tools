After, on other screen sizes

The same rules on phones with safe areas. A square or landscape work hits the screen width before the available height, so it fits the width and is centered vertically instead.

06

Build notes

How the size is worked out, plus a CSS starting point. The same rules apply to images and videos.

  1. Height first. Available height = screen height − top bar (52) − bottom area (126) − the top and bottom safe areas. The work is never taller than this.
  2. Width from the work’s own ratio. If the result is narrower than the screen, center the work and fill both sides with the detail page background.
  3. Wider works fit the width. If the height-first width is wider than the screen (square or landscape works), fit the width and center vertically. This is exactly object-fit: contain; never cover.
  4. Nothing on top of the work. The back button gets its own top bar. The title, Like, Collect, Share and Generate move into the bottom area.
  5. Use 100dvh, not 100vh. On mobile browsers 100vh includes the area behind the address bar, which pushes the bottom off screen. env(safe-area-inset-*) needs viewport-fit=cover in the viewport meta tag.
/* Layout: the middle row is the available height */
.detail        { height: 100dvh; display: flex; flex-direction: column;
                 background: var(--detail-bg); }
.detail-top    { flex: none; height: calc(52px + env(safe-area-inset-top));
                 padding-top: env(safe-area-inset-top); }
.detail-media  { flex: 1; min-height: 0; }
.detail-media img,
.detail-media video { display: block; width: 100%; height: 100%;
                      object-fit: contain; }
.detail-bottom { flex: none; height: calc(126px + env(safe-area-inset-bottom));
                 padding-bottom: env(safe-area-inset-bottom); }

/* Same size in JS, height first */
